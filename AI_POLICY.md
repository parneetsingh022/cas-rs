# AI Usage Policy

We welcome contributors who use AI tools to assist in their workflow. However, to maintain a high-quality codebase and ensure productive collaboration, we require all contributors to adhere to the following guidelines regarding Artificial Intelligence and Large Language Models (LLMs).

## 1. Code Generation is Permitted (With Accountability)
You are welcome to use tools like GitHub Copilot, Cursor, ChatGPT, or similar AI assistants to help you write code. However, **you are 100% responsible for the code you submit.** 

* We hold all pull requests to the same high standard, regardless of how the code was authored.
* You must fully understand every line of code you submit. If you cannot explain the logic, handle edge cases, or fix bugs introduced by your PR, it will not be merged.
* You are responsible for ensuring the AI did not introduce security vulnerabilities or copy strictly licensed code.

## 2. No Autonomous Agents
We require a "human in the loop" for all contributions. Pull requests, issues, or comments submitted completely autonomously by AI agents or bots will be closed immediately. A real human must actively review, test, and submit the work.

## 3. No AI-Generated Communication
**Do not use AI to write issue reports, pull request descriptions, or replies to maintainers.**

Reviewing code and discussing architecture requires precise, context-aware communication. AI-generated text is often overly verbose, confidently incorrect, or misses the core point entirely, which wastes maintainer time. 
* Write your PR descriptions and comments yourself. 
* Keep it brief, direct, and to the point. We prefer short, authentic human communication over polished but empty AI-generated essays.

## 4. Exception for Translation
If English is not your first language and you use an LLM to translate your thoughts, that is completely acceptable! In these cases, please include your original text in your native language alongside the English translation. This helps prevent misunderstandings if the AI hallucinates or mistranslates technical terms.
